# Chrome Web Store 掲載素材

Chrome Web Store の掲載情報に使う文章と画像を管理します。拡張機能のビルドには含まれません。

| パス                           | 内容                                                  | ストアの入力欄                        |
| ------------------------------ | ----------------------------------------------------- | ------------------------------------- |
| `listing/description.txt`      | 説明文（プレーンテキスト・最大16,000文字）            | ストアの掲載情報 › 説明               |
| `listing/privacy-practices.md` | 単一用途・権限の理由・リモートコードの回答            | プライバシーへの取り組み              |
| `screenshots/`                 | スクリーンショット（1280×800 または 640×400、1〜5枚） | ストアの掲載情報 › スクリーンショット |
| `promo/`                       | プロモーションタイル（小 440×280、マーキー 1400×560） | ストアの掲載情報 › プロモーション画像 |

- 要約（132文字まで）は `wxt.config.js` の `manifest.description` が使われます。
- ストアアイコン（128×128）は `public/icons/128.png` を使います。
- プライバシーポリシーはリポジトリ直下の `PRIVACY.md` です。
- 画像サイズや必須項目は変わることがあるため、提出時に開発者ダッシュボードで確認してください。
