# プライバシーへの取り組み（開発者ダッシュボードの回答）

0.6.0公開時に開発者ダッシュボードの「プライバシーへの取り組み」タブへ入力する下書きです。公開中の0.5.0向けの申告はまだ変更しません。各見出しの下のコードブロックを、該当する欄にそのまま貼り付けます。

## 単一用途の説明

```
閲覧中のWebページに書かれた日程を見つけ、選んだ日時と内容をカレンダーへ取り込めるよう、Googleカレンダーの予定作成画面を開くか、予定ファイル（.ics）としてダウンロードすること。
```

## 権限を要求する理由

### activeTab

```
ユーザーが拡張機能のアイコンを押したタブに限って、そのページの本文・構造化データ・タイトル・URLを読み取り、日程の候補を見つけるために使います。すべてのサイトへの常時アクセス（ホスト権限）は要求しません。
```

### scripting

```
アイコンを押したタブに、拡張機能に同梱したコンテンツスクリプトを挿入するために使います。このスクリプトは、ページの文字を読み取る処理、見つけた日程の位置をページ上で強調表示する処理、予定のタイトル・場所・詳細をクリックで取り込む処理を行います。外部から取得したコードは実行しません。
```

### storage

```
ユーザーが変更した設定（移動時間、予定タイトルの書式、候補の並び順、カラーテーマ）を端末内に保存するために使います。ページの内容や日程は保存しません。
```

## リモートコードの使用

「いいえ、リモートコードを使用していません」を選びます。

実行するコードはすべて拡張機能のパッケージに含めています。外部のスクリプトの読み込み、`eval` などによる文字列のコード実行、外部からのコードの取得はしていません。理由の入力欄が表示された場合は、次の文を貼り付けます。

```
すべてのコードは拡張機能のパッケージに含まれています。外部のスクリプトやWebAssemblyの読み込み、eval等による文字列からのコード実行は行っていません。
```
