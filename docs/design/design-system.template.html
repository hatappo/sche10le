02

色と状態

基本の7色は標準テーマ「千歳緑」のCSS変数から取得。銀鼠・水浅葱・藍鉄・黒茶・紫紺でも、色・枠・文字の太さ・チェックの役割を揃える。下のUI見本で6テーマを切り替えられる。

{{SWATCHES}}
内容の選択中 — 白地と深緑の枠#ffffff8c / #2c6045
取得済み — 淡緑と末尾のチェック ✓#f1f5ed / #788171
書式を確認してください#fff0ed / #972d28

候補・補助操作は白系の背景と細い枠、影なし。再スキャン・選び直すは背景なしの緑文字とし、ホバー時に下線を出す。操作ボタンの深緑の塗りは「Googleカレンダーで開く」に使う。

コントラスト（紙色に対して）：主文 {{INK_CONTRAST}}:1 ／ 補助色 {{MUTED_CONTRAST}}:1。補助色は通常サイズの文字の4.5:1を満たさない。重要な説明は主文色を優先する。状態色とオーバーレイ色には、共通変数とは別の実装値がある。

03

文字と余白

ブランドはセリフ体。日付と操作文はOSの日本語フォント。操作の説明は読みやすい日本語サンセリフ。精密さが必要な書式には等幅を使う。

GEORGIA / BRAND
Sche10le · 10

ロゴ原稿 20px・600。表示例は拡大。

SYSTEM / HIRAGINO
ページ上の文字をクリック

本文 14px / 1.55 ／ 補足 12px。

SYSTEM / DATE & TIME
14:00–16:00

候補の時刻も本文と同じ書体・14px。

MONOSPACE / FORMAT
{from:HHmm} {title}

入力欄は16px。OS標準のフォントを利用。

16px · 本文の左右余白
12px · 候補カードの角丸
44px · 操作対象の最小高さ
360px · PCのドロワー幅

画面幅に応じて下部シートと右側ドロワーを切り替える。狭幅では左右12pxの余白を取り、入力・内容のスクロール領域を確保する。

04

UIの部品

0.6.0開発版の共通シートCSSを使った操作見本。候補に触れて展開し、登録方法や取得結果の行を選べる。実ページの読み取りや保存は行わない。

01 / CHOOSE

候補と補助操作を分ける

拡張アイコンで起動し、日程はカード、再スキャンはリンク風に表示する。再スキャンは件数の隣に、設定はヘッダの歯車に置く。一覧と設定ではフッタを省く。注入できないページでは別の案内ページを表示する。

02 / PICK

取得結果そのものが入口

取得バーの3ボタンには、現在の内容を最大2行で表示する。確認画面のタイトル・場所・詳細の行全体がクリック対象。現在の項目は白系の背景・深緑の枠・項目名の太字で示す。「選択中」ラベルは置かず、完了は淡緑の面と末尾のチェックで示す。

03 / OPEN

主操作は一か所に

確認画面の下部に「Googleカレンダーで開く」とICSボタンを置く。取得途中でも取得バー右上の展開ボタン（内容を確認）から進める。保存自体はカレンダー側で行う。

04 / SETTINGS

設定では面ごと切り替える

一覧・確認から設定専用の画面へ切り替える。移動時間・書式・テーマを細い区切り線と余白でまとめ、背景色や影は増やさない。自動保存を統一し、エラーは赤い枠と理由で伝える。名言はこの画面の最下部だけに置く。

資料内の見本です。設定値は保存されません。

05

動きと操作

動きは、対象がどこにあり、何が終わったかを伝えるために使う。ページ上の操作バーは手順を進めても大きさとボタン位置を保つ。

実装の共通シートCSSを使用した静的見本。取得バーの高さは212px。案内帯を上下移動でき、初期位置へ戻せる。

取得完了を、光とチェックで伝える

タイトル活版印刷のワークショップ

動きを減らす設定では、静的なチェックだけで伝える。

320msシートの高さの変形
180msホバーから候補を開くまで
850ms取得した項目のラベルの光
1.2秒カレンダーボタンの光
10秒次の主操作の光までの間隔
3回主操作の光の上限

元の日時はスクロールと波紋（1.1秒×3回）で示す。対象以外を48%で暗くし、小さな文字も見つけやすくする。右上の「×」は全段階で同じ閉じる操作にし、取得済みの内容を残す。

07

継承するルール

何かを足すときも、ユーザーの判断と移動を増やさない。見た目だけでなく、振る舞いと言葉まで揃える。

選択中と、押せるものを混同しない

主操作は深緑、初回スキャンは白系の背景と枠。内容の選択中は白地・深緑の枠・太字、完了は淡緑とチェック。補助操作のホバー面だけで完了を表さず、色と形を組み合わせる。

ボタンは全体を押せるようにする

文字だけをリンクにしない。ホバーだけでなく、キーボードフォーカスでも同じ情報に到達できるようにする。

説明を足す前に、操作を整える

狭いパネルにヒーローコピーや自明な案内を置かない。エラーやモード変更など、必要な瞬間に説明する。

確認できる事実をラベルにする

「スキャン」「再スキャン」「閉じる」を統一。カレンダーを開いただけで「保存完了」と伝えない。

動きを減らしても、意味を残す

移動や波紋を止めても対象・選択状態・完了が分かること。資料の再生デモもOS設定に従う。

素材と実装を一緒に見直す

フォント・色・ロゴ比率の変更はアイコンとストア素材へも反映。実装値と設計上の推奨を区別して記録する。
