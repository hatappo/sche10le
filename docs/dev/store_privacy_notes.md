# ストア申告とプライバシーポリシーの照合メモ

対象：Sche10le 0.3.0（.icsエクスポート追加）。公開文書は [PRIVACY.md](../../PRIVACY.md)。このメモは申告準備用であり、開発者ダッシュボードへの入力・提出はまだ行っていない。

## 単一の目的

ユーザーが指定したWebページの日程を抽出し、選択したテキストとともにGoogleカレンダーの予定作成画面へ渡すか、予定ファイル（.ics）としてダウンロードする。

## データの取り扱い

| 取り扱う情報 | 用途・保存・送信 | 申告時に照合する項目 |
| --- | --- | --- |
| ページ本文・構造化データ・タイトル・選択した文字 | 端末内で日程候補と予定を作成。明示的にダウンロードする.icsを除き永続保存しない。カレンダーを開く操作で予定の内容をGoogleへ渡す | ウェブサイトのコンテンツ（Website content） |
| 対象ページのURL | 予定の出典として詳細末尾に付加し、カレンダーを開く操作でGoogleへ渡す。ダウンロードする.icsにも出典として含める。閲覧履歴を列挙・蓄積する機能はない | ウェブ履歴（Web history）のURLに関する定義と照合。履歴APIを使わないことを理由にURLの取り扱いを申告から省かない |
| 移動時間・タイトル書式・AI設定・並び順 | 拡張機能のローカルストレージに保存。アンインストールで削除 | ローカル設定の保存として説明 |
| AIに渡すページ本文の一部 | 初期状態では無効。利用可能な環境でChromeに組み込まれたAIモデルが端末内で推論。モデルのダウンロードはChromeが行う | 外部AIサービスへの本文送信とは申告しない |

本文・選択した文字には氏名や住所などが含まれる場合がある。データ種別のチェック欄は、提出時点のダッシュボードの定義と実際の取り扱いに照らして最終確認する。「端末内の処理のみ」「開発者に送信しない」を「データを一切扱わない」と言い換えない。

## 権限の用途

| 権限 | 申告する用途 |
| --- | --- |
| `activeTab` | アイコン操作で許可されたタブのページを、一時的なアクセス権限で読み取る |
| `scripting` | 許可されたページに日程取得・文字選択・元の文字列の強調表示を行うスクリプトを必要時だけ注入する |
| `sidePanel` | 日程候補、予定のプレビュー、設定をサイドパネルに表示する |
| `storage` | 移動時間・タイトル書式・AI設定・候補の並び順を端末内に保存する |

本番manifestは上記4権限のみ。`tabs`権限、全サイトのホスト権限、常時実行のContent Scriptは要求しない。タブ切り替え・ページ遷移のイベントは選択解除に使い、自動スキャンには使わない。スキャン契機はアイコン操作・サイドパネル初回読み込み・再スキャンで、いずれも対象ページへのアクセス権限が必要。

予定ファイルはBlobとdownload属性で端末内生成するため、`downloads`権限や外部送信は追加しない。ファイルはユーザーが管理し、拡張のアンインストールでは削除しない。

## 提出前の照合

- 公開されたPRIVACY.mdのURLをポリシー欄に入力し、未ログインでも日英両方を読めることを確認する。
- Googleへの予定情報・元ページURLの送信と、ローカルAIの説明を、ストア紹介文・データ申告・ポリシーでそろえる。
- データの販売・広告目的の利用・アクセス解析は行わず、申告した単一目的のために利用する。Limited Use等の確認事項は実装・ポリシーと照合して回答する。
- JavaScriptは拡張に同梱しており、リモートコードは使用しない。ChromeによるAIモデルのダウンロードと、外部JavaScriptの読み込みを混同しない。
- 仕様変更時は日本語・英語のポリシーとダッシュボードの申告を一緒に見直す。

参照：[プライバシー申告欄の公式ガイド](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)、[Limited Use](https://developer.chrome.com/docs/webstore/program-policies/limited-use)。
